# SwitchPath — Career Change Roadmaps for 2026

> Free career-change roadmaps for 25+ paths — cybersecurity, nursing, electrician, UX design & more.

**SwitchPath** helps career changers plan their next move with **step-by-step roadmaps, real salary data, and time-to-hire estimates** across 25+ careers.

## ✨ Features

- 🗺️ **25+ career roadmaps** — tech, healthcare, trades, design, finance
- 💰 **Real salary data** — US market figures with growth projections
- ⏱️ **Time-to-hire timelines** — know exactly how long each path takes
- 🎓 **Certification guides** — the exact credentials that matter
- 🧮 **Career cost calculator** — estimate training & transition costs
- 📱 **Responsive design** — clean reading on any device

## 🛠️ Built With

- HTML5 + CSS3 + vanilla JavaScript
- No frameworks — fast, lightweight, SEO-friendly
